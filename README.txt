SRISHTI ENTERPRISES Scratch Coupon
=================================

Run:
  npm install
  npm start

Pages:
  /           Customer scratch coupon
  /admin.html Admin: generate coupons + WhatsApp links

Important:
This starter stores coupons in coupons.json. On hosting platforms with ephemeral
storage, data can reset after a redeploy/restart. For permanent one-time redemption,
connect a persistent database (e.g. PostgreSQL/Supabase) before using it for real
promotions.

Render:
Environment: Node
Build Command: npm install
Start Command: npm start
